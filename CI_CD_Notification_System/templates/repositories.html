GitHub Actions setup

  1. In your GitHub repository, open Settings → Secrets and variables → Actions.
  2. Add repository secret CI_NOTIFICATION_URL with your deployed website address followed by /api/builds.
  3. Add repository secret CI_NOTIFICATION_TOKEN. It must match the token configured as an environment variable on this Flask server.
  4. Copy the .github/workflows/ci.yml file from this project into the same path in your GitHub repository.

For local testing, GitHub-hosted runners cannot reach localhost. Deploy the Flask app or use a secure temporary tunnel.
